# Simon-game
A browser-based implementation of the classic **Simon Memory Game** built using **HTML, CSS, JavaScript, and jQuery**. The game tests the player's memory by generating an increasingly long sequence of colors that must be repeated correctly.

## Features
- Random color sequence generation
- Visual animations for button presses
##  Tech Stack

- HTML
- CSS
- JavaScript (ES6)
